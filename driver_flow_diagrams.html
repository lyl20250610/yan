📊 五、三大驱动协议对比总结

特性 🔌 I2C 🎵 I2S 📺 SPI
总线编号 I2C_NUM_0 (传感器) + I2C_NUM_1 (触摸) I2S_NUM_0 (全双工) SPI2_HOST
引脚 Bus0: SDA=9 SCL=8
Bus1: SDA=6 SCL=7 		BCLK=4 LRC=5 DIN=21 DOUT=3 SCK=12 MOSI=11 MISO=13 CS=10 DC=15
时钟速率 Bus0: 100kHz (标准) · Bus1: 400kHz (快速) 采样率 16kHz · BCLK = 16k×16×2 = 512kHz 27MHz (SPI 时钟)
DMA 不使用 (短数据 · 阻塞式) 使用 (RX + TX 双通道 DMA) 使用 (SPI_DMA_CH_AUTO · 大块像素)
设备数量 Bus0: 3个 (BH1750+SGP30+APDS9960) · Bus1: 1个 (FT6336) 2个 (MEMS麦克风 + MAX98357功放) 1个 (ILI9341 LCD)
寻址方式 7位地址 + R/W 位 · 动态扫描发现 无寻址 · 点对点 · 时分复用 (TDM) CS 片选 (GPIO10) + DC 命令/数据选择
数据格式 字节流 · 寄存器地址+数据 16bit PCM 采样 · Philips 标准格式 8位命令 + 16位像素 (RGB565) · BGR Big-Endian
同步机制 Mutex (BH1750) · 无 (其他阻塞式) Critical Section (环形缓冲读写指针) · Queue (命令ID) Binary Semaphore (DMA 传输完成 ISR → flush等待)
错误处理 5次连续失败 → disable → 每30秒 retry reinit 读取超时 1000ms → continue 跳过本轮 · 心跳日志 draw_bitmap 失败 → WARNING 日志 · flush 超时 200ms
缓冲区 无内置缓冲 (i2c驱动内部FIFO) 环形缓冲 64KB PSRAM (2秒音频) · DMA 缓冲 4KB 双缓冲 2×320×15×2 = 19.2KB DMA Heap
主要API i2c_master_cmd_begin() · i2c_cmd_link_create() i2s_channel_read() · i2s_channel_write() esp_lcd_panel_draw_bitmap() · spi_bus_initialize()
驱动层封装 裸 I2C API + 各传感器组件封装 voice 组件: voice_io_init / voice_read_audio / voice_play_audio display 组件: display_init / display_wait_for_flush + LVGL port
